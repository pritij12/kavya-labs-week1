# Kavya Labs, Week 1: Landing page

Brief: hero, features, footer. Tech: Next.js 14 and Tailwind CSS.
This page needs **no login, no database and no environment variables**, so it deploys anywhere.

## Files

```
week1-landing/
├── app/
│   ├── page.js        The landing page (header, hero, features, footer)
│   ├── layout.js      Page title and wrapper
│   └── globals.css    Tailwind
└── package.json, tailwind.config.js, postcss.config.js, .gitignore
```

## Run it

```
npm install
npm run dev
```
Open http://localhost:3000

## Submit (GitHub + Vercel)

1. Create a GitHub repository (for example `kavya-labs-week1`) and upload this folder (the files must be at the top level of the repo).
2. On vercel.com choose **Add New > Project**, import the repository, and click **Deploy**. No settings are needed.
3. Submit the GitHub URL and the Vercel URL.
4. Open your Vercel link yourself first and check that you can see the hero, the features and the footer.

Kavya Labs is a fictional company from a virtual startup exercise.
